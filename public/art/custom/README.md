# ภาพการ์ดกำหนดเอง / ภาพ AI

วางไฟล์ภาพไว้ที่ `<ประเภท>/<id>.webp` (หรือ .png / .jpg) แล้วเซิร์ฟเวอร์จะใช้แทนภาพที่วาดจากโค้ดโดยอัตโนมัติ

| โฟลเดอร์ | ใช้กับ | ตัวอย่าง |
|---|---|---|
| `heroes/` | ภาพฮีโร่ (สี่เหลี่ยมจัตุรัส 1:1) | `heroes/merlin.webp` |
| `dark/` | ภาพด้านมืดของฮีโร่ (1:1) | `dark/mordred.webp` |
| `cards/` | ภาพการ์ดมนตรา (5:4) | `cards/excalibur.webp` |
| `threats/` | ภาพภัยพิบัติ (5:4) | `threats/dragon.webp` |

- ชื่อไฟล์ต้องเป็นรหัสการ์ด (ตัวพิมพ์เล็ก a-z, 0-9, _) — ดูรหัสได้ในสตูดิโอ `/studio.html`
- ภาพต้องไม่มีกรอบหรือตัวอักษร เกมจะใส่กรอบการ์ดให้เอง
- ลบไฟล์ออก = กลับไปใช้ภาพที่วาดจากโค้ด

## ส่งภาพจาก Gemini มาให้ Claude จัดการ
- Prompt ทั้งหมดอยู่ใน [PROMPTS.md](PROMPTS.md) (เลข 01–74)
- อัปโหลดภาพดิบไว้ที่ `inbox/` ตั้งชื่อเป็นเลขลำดับหรือรหัส (เช่น `01.png`, `arthur.png`) — เซิร์ฟเวอร์ไม่ใช้ไฟล์ในโฟลเดอร์นี้
- Claude จะตัดขอบ/ลายน้ำ ย่อเป็น WEBP 1024px แล้วย้ายไปไว้ที่ `heroes/`, `dark/`, `cards/`, `threats/`
