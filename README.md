# CAMELOT: ARCANE REALM (ศึกบัลลังก์มนตราแห่งคาเมลอต)

เกมการ์ดซ่อนบทบาทแนวแฟนตาซี (Fantasy Hidden Role Card Game) จักรวาลกษัตริย์อาเธอร์และอัศวินโต๊ะกลม เล่นออนไลน์ผ่านเบราว์เซอร์
รองรับมือถือ มีระบบห้อง บอทที่พูดคุยและหลอกกันได้ และกลับเข้าเกมได้เมื่อหลุด — พัฒนาต่อยอดจากเอนจิน 3kingdom แล้วยกเครื่องกลไกใหม่ทั้งหมด

## เริ่มใช้งาน

```bash
npm install
npm start            # http://localhost:3000
```

ตัวแปรสภาพแวดล้อม: `PORT` (ค่าเริ่มต้น 3000), `BOT_DELAY` (ms ระหว่างการตัดสินใจของบอท ค่าเริ่มต้น 900)

ทดสอบ: `npm test`

## บทบาท (4–10 คน, ฝึกเล่น 2–3 คนได้)

| บทบาท | การเปิดเผย | โบนัส | เงื่อนไขชนะ |
|---|---|---|---|
| กษัตริย์ (The High King) | หงายหน้าเสมอ | เลือดสูงสุด +1, การ์ดเริ่มต้น +1 | กำจัดลัทธิเงามืดและผู้แฝงตัว |
| อัศวินผู้ภักดี | ลับ | – | ปกป้องกษัตริย์ และกำจัดศัตรูของคาเมลอต |
| ลัทธิเงามืด | ลับ | – | สังหารกษัตริย์ **หรือ** ดันแถบหายนะถึง −10 |
| ผู้แฝงตัว | ลับ | ต้านทานคำสาปได้ 1 ครั้ง | เป็นคนสุดท้ายที่ยืนอยู่ |

## ระบบหลัก

- **ธาตุ = อักขระรูน**: ♣ ศักดิ์สิทธิ์ (Aegis) · ♦ อัคคี (Ignis) · ♠ พายุ/เวทมนตร์ (Aether) · ♥ เงามืด (Umbra) — สำรับ 108 ใบ ธาตุละ 27 ใบ
- **สำรับ**: ศรเวท 30 (ธาตุอัคคี ♦ = Flame Strike เผาอุปกรณ์), ม่านบาเรีย 15, น้ำอมฤต 8, มหาเวทฉับพลัน 30, คำสาปหน่วงเวลา 8, ยุทโธปกรณ์ 15 (ศาสตราวุธ 4 ชนิด, เครื่องราง 3 ชนิด, สัตว์เทวะพาหนะ 2 ชนิด)
- **ฮีโร่ 25 ตัว** ใน 4 ขั้วอำนาจ (ราชสำนัก · ลัทธิเร้นลับ · วิหารอวาลอน · ผู้พิทักษ์จอก) พร้อมทักษะครบ รวม "ดาบในศิลา" สกิลประมุขของอาเธอร์
- **ลำดับเทิร์น**: รุ่งอรุณ → ผนึกคำสาป → เบิกมนตรา (จั่ว 2) → ร่ายเวทและทำศึก → สละพลัง → สนธยา
- **กฎพิเศษ**: สังหารลัทธิเงามืดได้จั่ว 3 ใบ · ตราบาปสังหารสายเลือดเดียวกัน · สภาวะวิญญาณแตกดับ (ใช้น้ำอมฤตชุบชีวิต)

### นวัตกรรมกลไกใหม่ (Original Systems)

1. **🧭 โต๊ะกลมมนตรา** — ระยะคิดจาก "โซน" ไม่ใช่ที่นั่ง: วงแหวนบัลลังก์ ♛ · หอคอยเงามืด ☾ · ทุ่งสงคราม ⚔ · วิหารอวาลอน ✧ และศูนย์กลางมนตรา ✺
   โซนเดียวกันหรือศูนย์กลาง = 1, โซนติดกัน = 2, ฝั่งตรงข้าม = 3 (พาหนะ ±1 ยังใช้ได้) เคลื่อนที่ได้เทิร์นละ 1 ครั้ง และผลัก/ดึงศัตรูด้วยมหาเวท
2. **ᚱ ผสานรูน** — ทิ้งการ์ด 2 ใบตามธาตุเพื่อร่ายมหาเวท 10 แบบ (ครบทุกคู่ธาตุ) เช่น Ignis+Ignis = มหาเพลิงผลาญ (2 ดาเมจทะลุเกราะ), Ignis+Aether = ศรเพลิงวิถีไกล (ไม่จำกัดระยะ),
   Aegis+Umbra = เกราะหนามทมิฬ, Aether+Aether = คลื่นจิตผลัก/ดึง — การ์ดทุกใบมีประโยชน์ ไม่มีเทิร์นที่ทำอะไรไม่ได้ (ฮีโร่อวาลอนผสานได้ 2 ครั้ง/เทิร์น)
3. **🌑 นาฬิกาหายนะ / 🏆 จอกศักดิ์สิทธิ์** — แถบ −10…+10: สุริยุปราคาคืบคลานเองทุกรอบ (เร็วขึ้นเมื่อเกมยืดเยื้อ และหยุดเมื่อลัทธิเงามืดสิ้นชีพหมด — ช่วงท้ายจึงเป็นศึกระหว่างผู้แฝงตัวกับฝ่ายกษัตริย์ล้วนๆ), ลัทธิเงามืดทำ "พิธีกรรมสังเวย" (เสียเลือด 1 + ทิ้ง 1 ใบ),
   อัศวินออก "แสวงบุญ" (ทิ้ง 2 ใบ) ถึง −10 ลัทธิเงามืดชนะทันที ถึง +10 จอกปรากฏ (ครั้งเดียว): ลัทธิเงามืดเสียเลือดครึ่งหนึ่ง กษัตริย์อมตะชั่วคราว
4. **👻 วิญญาณแห่งอวาลอน** — ผู้สิ้นชีพไม่ตกรอบ กลายเป็นวิญญาณที่ยังมีเทิร์นและเด็ควิญญาณ: เสียงกระซิบจากสายหมอก (แอบดูมือ), เปลี่ยนผันชะตา (สั่งตัดสินใหม่),
   สละไอวิญญาณ (รับดาเมจถึงตายแทนเพื่อน) — และชนะร่วมกับทีม
5. **📜 สัตยาบันและพันธสัญญา** — ประกาศตอนรุ่งอรุณ: ความกล้า (ตีเฉพาะคนเลือดสูงสุด → ศรเวท +1 และป้องกันไม่ได้), ความเมตตา (ไม่ทำร้ายใคร → รักษา 2 · ประกาศไม่ได้เมื่อเหลือดวลกัน 2 คน),
   พันธสัญญาโลหิต (เสียเลือด 1 → จั่ว 3) ผิดสัตยาบัน = ตราบาป (Fallen): เปิดการ์ดในมือ 2 ใบ และเสียทักษะ 1 รอบ

## 🖼 ภาพประกอบความละเอียดสูง (สร้างจากโค้ด บันทึกถาวร)

ภาพทุกใบ — ฮีโร่ 25 ตัว (256×256), การ์ด 20 ชนิด (256×208), หลังไพ่, แผนที่โต๊ะกลม และพื้นโต๊ะ — **วาดจากโค้ดล้วน** ด้วยตัววาดใน `public/artgen/`
(ไม่ใช้ AI และไม่ใช้ภาพจากที่อื่น) แล้วบันทึกถาวรเป็น PNG ใน `public/art/` พร้อม `manifest.json` ลายนิ้วมือ SHA-256

ตัววาดรุ่นใหม่ (artgen v3) ยกระดับจาก pixel art 48px มาเป็นภาพวาดแบบ painterly:
- วาดที่ความละเอียด 3 เท่าแล้วย่อ (supersampling) → ขอบเรียบไม่มีรอยหยัก
- เชดเดอร์รายพิกเซล: ไล่สีเชิงเส้น/รัศมี, แสงเงาแบบโลหะ/ผ้า, พื้นผิวจาก fractal noise
- เลเยอร์ + เบลอ สำหรับแสงเรือง (glow), เงานุ่ม และแสงขอบ (rim light) ตามสีของขั้วอำนาจ
- เส้นโค้ง Catmull-Rom/Bézier สำหรับผม เครา ผ้าคลุม และเส้นสาย
- ตัวเข้ารหัส PNG ใช้ฟิลเตอร์รายแถวแบบปรับตัว → ภาพ 48 ไฟล์รวมเพียง ~2.4 MB

การใช้งาน:
- ดูภาพพร้อมข้อมูลการ์ดได้ที่ `/gallery.html` (ติ๊ก "วาดใหม่สด" เพื่อให้เบราว์เซอร์วาดใหม่จากโค้ดแล้วเทียบกับไฟล์ทีละพิกเซล)
- `npm test` ตรวจว่าไฟล์ทุกไฟล์ตรงกับที่ตัวสร้างภาพวาดทุกพิกเซล — ถ้ามีใครแก้หรือเปลี่ยนไฟล์ การทดสอบจะไม่ผ่าน
- ผู้ดูแลที่ต้องการเปลี่ยนภาพ: แก้ `public/artgen/designs.js` แล้วรัน `npm run build:art` และ commit (ตรวจอย่างเดียว: `npm run build:art -- --check`)

## ฟีเจอร์ออนไลน์

- **ระบบห้อง**: สร้างห้องได้รหัส 4 ตัว ส่งลิงก์ `?room=CODE` ให้เพื่อน หัวห้องเพิ่ม/เตะบอทและเริ่มเกมได้ ผู้เล่น 2–10 คน
- **กลับเข้าเกม (rejoin)**: เบราว์เซอร์เก็บ token ไว้ใน localStorage ปิดแท็บ/รีเฟรช/เน็ตหลุดแล้วเปิดใหม่ ระบบพากลับที่นั่งเดิมพร้อมคำสั่งที่รออยู่
- **บอท** เล่นตามบทบาท เดาฝ่ายจากพฤติกรรมและบทบาทที่เปิดเผยแล้ว รู้จักทุกระบบ (เคลื่อนที่หาระยะ, ผสานรูน, ดันแถบชะตา, ประกาศสัตยาบัน, ใช้การ์ดวิญญาณ)
  — ลัทธิเงามืดเล็งกษัตริย์เป็นหลัก, ผู้แฝงตัวรักษาสมดุล ต้านสุริยุปราคา ลอบกำจัดอัศวินเมื่อได้เปรียบ แล้วค่อยดวลกษัตริย์เป็นคนสุดท้าย
- **บอทพูดคุยและหลอกกัน** (`server/game/banter.js`): ลัทธิเงามืด/ผู้แฝงตัวแกล้งทำเป็นภักดี กล่าวหากัน ประจานคนทำพิธีกรรมสังเวย วิญญาณกระซิบใบ้
- แชทในห้อง, บันทึกเหตุการณ์, ตัวจับเวลา, แอนิเมชันการ์ด/ตัดสิน/ดาเมจ/การเคลื่อนที่

## โครงสร้าง

```
server/
  index.js        HTTP + Socket.IO
  rooms.js        ระบบห้อง, token/rejoin, broadcast สถานะรายคน
  game/
    engine.js     กฎเกม (async state machine) + โซน, ผสานรูน, แถบชะตา, วิญญาณ, สัตยาบัน
    cards.js      สำรับ 108 ใบ + ธาตุ
    heroes.js     ฮีโร่ 25 ตัว / ทักษะ / บทบาท / ขั้วอำนาจ
    bot.js        AI บอท
    banter.js     บทสนทนาของบอท
public/           ไคลเอนต์ (HTML/CSS/JS ล้วน ไม่ต้อง build)
  gallery.html    คลังภาพ + ฐานข้อมูลการ์ด (อ่านอย่างเดียว)
  artgen/         ตัววาดภาพความละเอียดสูง (raster.js, designs.js) ใช้ได้ทั้ง Node และเบราว์เซอร์
  art/            ภาพที่สร้างแล้ว (PNG) + manifest.json — ห้ามแก้ด้วยมือ
scripts/
  build-art.js    สร้าง/ตรวจสอบภาพทั้งหมด
  png.js          ตัวเข้ารหัส PNG (adaptive row filters)
test/             ทดสอบ engine (จำลองเกมบอทหลายร้อยเกม), ระบบ CAMELOT, ภาพ และ end-to-end ผ่าน socket
```
